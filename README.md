# Roller Coaster Trip Planner

A website that makes planning any coaster trip easier with a built in map, itinerary, and nearby park suggestions. 

Check it out here:
https://coaster-trip-planner.onrender.com/

Note: This project is still a work in progress. The database of parks is still being updated. Right now, only parks with >=2 coasters and in states northeast of Pennsylvania are functional.
